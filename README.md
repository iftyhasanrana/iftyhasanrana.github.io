# Ifty Hasan Rana — IT & Cybersecurity Portfolio

A static, mobile-friendly portfolio website ready for GitHub Pages. No build tools or hosting subscription required.

## Preview locally

Open `index.html` in a browser. It loads local `styles.css` and `script.js` files.

## Publish at your own GitHub Pages address

1. Sign in to https://github.com/ (create a free account if needed).
2. Create a **public** repository named `YOUR-USERNAME.github.io`, replacing YOUR-USERNAME with your exact GitHub username.
3. Upload `index.html`, `styles.css`, `script.js`, and optionally this `README.md` to the repository root using **Add file → Upload files**. Commit the files to `main`.
4. Open the repository **Settings → Pages**. In **Build and deployment**, select **Deploy from a branch**, then `main` and `/(root)`, and click **Save**.
5. Visit `https://YOUR-USERNAME.github.io/` after GitHub publishes it.

Official guide: https://docs.github.com/en/pages/quickstart

## Personalize before sharing with recruiters

- Replace `https://www.linkedin.com/` and `https://github.com/` in `index.html` with your *actual* profile URLs. The current buttons are generic placeholders.
- Add links to public GitHub repositories, LinkedIn project entries, demo videos, or sanitized PDF reports for the relevant project cards.
- Check every description against your original project files and LinkedIn entries. This is a starter draft based on existing context, not an independent audit of projects.
- Add your resume PDF only when you're comfortable sharing it publicly. Do not post your address, phone number, student ID, internal work materials, real credentials, private security results, or other sensitive information.
- Update graduation information if it changes.
- Optional: add a proper contact email or a working form service (not included); the website does not send messages by itself.
